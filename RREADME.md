# Auto Hotspot для Windows 11

[English version](README.md)

Автоматически включает **Мобильный хот-спот** Windows при входе в систему и следит, чтобы он оставался включённым. Ничего не нужно включать вручную и вписывать в скрипт.

## Возможности

- Запускается при каждом входе в систему, скрыто, без окон.
- Следит за хот-спотом: каждые 30 секунд проверяет и включает его снова, если он выключился.
- Ждёт сеть после загрузки, так что работает, даже если интернет появился не сразу.
- Использует имя сети и пароль, уже заданные в Windows. В скрипте ничего не хранится.
- Установка одним кликом: создаётся задача в планировщике с перезапуском при сбое.
- Небольшой лог для диагностики.

## Файлы

| Файл | Назначение |
|---|---|
| `install-hotspot.bat` | Установщик: запрашивает права администратора, копирует скрипт, создаёт задачу, запускает её |
| `Enable-Hotspot.ps1` | Скрипт PowerShell, который включает хот-спот и постоянно его проверяет |

## Требования

- Windows 10 или 11
- Wi-Fi адаптер с поддержкой режима точки доступа. Проверка: `netsh wlan show drivers`, строка «Поддержка размещённой сети: Да» (`Hosted network supported : Yes`).
- Активное подключение к интернету (Ethernet или другая Wi-Fi сеть). Хот-спот раздаёт уже имеющееся подключение и без него не запустится.
- Права администратора (только для установки)

## Установка

1. Скачай или склонируй репозиторий.
2. Убедись, что `install-hotspot.bat` и `Enable-Hotspot.ps1` лежат в **одной папке**.
3. Запусти `install-hotspot.bat` двойным кликом и подтверди запрос UAC.
4. Дождись сообщения `Done`.

Установщик:

1. Запрашивает права администратора, если их нет.
2. Копирует `Enable-Hotspot.ps1` в `C:\ProgramData\AutoHotspot`.
3. Создаёт задачу `AutoHotspot` (триггер: вход в систему, наивысшие права, перезапуск раз в минуту при сбое, работает и от батареи).
4. Сразу запускает задачу.

Имя сети и пароль берутся из **Параметры → Сеть и Интернет → Мобильный хот-спот**. Windows создаёт значения по умолчанию, при желании измени их там. Там же можно отключить «Энергосбережение», чтобы Windows не гасила точку, когда никто не подключён (скрипт всё равно включит её обратно).

## Как это работает

Планировщик запускает `Enable-Hotspot.ps1`, который работает в бесконечном цикле:

1. Получает текущее подключение к интернету (`NetworkInformation.GetInternetConnectionProfile`).
2. Если подключения ещё нет, ждёт и проверяет снова.
3. Иначе читает состояние точки через `NetworkOperatorTetheringManager`.
4. Если хот-спот выключен, вызывает `StartTetheringAsync()`.
5. Пишет результат в лог, ждёт 30 секунд и повторяет.

API хот-спота требует пользовательской сессии, поэтому задача стартует при **входе** в систему, а не при загрузке. Чтобы точка поднималась без ввода пароля, включи автовход (`netplwiz`). Учитывай, что это снижает безопасность ПК.

## Настройка

В начале `Enable-Hotspot.ps1`:

```powershell
$CheckIntervalSeconds = 30   # как часто проверять состояние хот-спота
```

После правки запусти `install-hotspot.bat` ещё раз, чтобы скопировать новую версию и перезапустить задачу.

## Логи

`C:\ProgramData\AutoHotspot\hotspot.log` (очищается автоматически при размере больше 200 КБ).

```
Watchdog started
No internet connection profile yet, waiting...
StartTethering: Success
```

Состояние задачи:

```
schtasks /Query /TN "AutoHotspot"
```

## Остановка и удаление

Пока задача установлена, выключенный вручную хот-спот включится обратно в течение 30 секунд.

Временная остановка (от администратора), затем выключи хот-спот в настройках Windows:

```
schtasks /End /TN "AutoHotspot"
```

Полное удаление:

```
schtasks /End /TN "AutoHotspot"
schtasks /Delete /TN "AutoHotspot" /F
rmdir /S /Q C:\ProgramData\AutoHotspot
```

## Безопасность

- Точка всегда включена. Любой, кто знает пароль, сможет пользоваться твоим интернетом, поэтому задай сложный пароль.
- Задача работает с наивысшими правами. Папка `C:\ProgramData\AutoHotspot` по умолчанию недоступна для записи обычным пользователям, не меняй её права.
- Скрипт не делает сетевых запросов и не меняет настройки хот-спота, он только включает его.
- Постоянно включённая точка быстрее разряжает ноутбук и может снижать скорость, если интернет идёт через ту же Wi-Fi карту.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Хот-спот не включается, в логе `No internet connection profile yet` | Нет активного интернета. Подключи Ethernet или Wi-Fi. |
| В логе статус не `Success` | Адаптер или драйвер может не поддерживать режим точки доступа. Проверь `netsh wlan show drivers`, обнови драйвер. |
| Лога нет | Задача не запускалась. Проверь её в планировщике, столбец «Последний результат». |
| Работает только при ручном запуске | Убедись, что задача создана для твоего пользователя и ты входишь под ним же. |
| Установщик не находит `Enable-Hotspot.ps1` | Файлы лежат в разных папках. |

## Ограничения

Поведение зависит от Wi-Fi адаптера и драйвера. Старый способ `netsh wlan hostednetwork` не используется: на большинстве адаптеров Windows 11 он не поддерживается.
